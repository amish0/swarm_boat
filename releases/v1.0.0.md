# AI Boat Firmware v1.0.0

**Release date:** 2026-09-28

## Overview

Initial tagged release of the ESP32 two-wheel obstacle-avoiding boat firmware.

## Features

- Autonomous differential-drive control through an L298N dual H-bridge.
- Ultrasonic obstacle detection with servo-based left/right scanning.
- DHT11 temperature and humidity sensing.
- SSD1306 OLED and LED movement/heartbeat indicators.
- Buzzer alerts during obstacle scans and avoidance movement.
- Wi-Fi station mode and password-protected ArduinoOTA support.
- HiveMQ TLS/PubSubClient configuration and an MQTT payload implementation in source.

## Notes

- The MQTT publish call is commented out in this tag; the main loop does not actively publish telemetry.
- Browser Auto/Manual control and Audio mode are not included in v1.0.0.
- Wi-Fi and broker credentials are stored in firmware source; use private credentials for deployment.

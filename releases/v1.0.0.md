# AI Boat Firmware v1.0.0

**Release date:** 2026-09-28

## Overview

Initial tagged release of the ESP32 two-wheel obstacle-avoiding boat firmware.

## Features

- Autonomous differential-drive control through an L298N dual H-bridge: forward, reverse, left, right, and stop.
- Ultrasonic obstacle detection with filtered front readings and servo-based left/right scanning to select a clear direction.
- DHT11 temperature and humidity sensing.
- SSD1306 OLED status display and LED indicators for movement and heartbeat.
- Buzzer alerts during obstacle scans and avoidance movement.
- Wi-Fi station mode and password-protected ArduinoOTA firmware updates.
- HiveMQ TLS/PubSubClient configuration and an MQTT payload implementation are present in the source.

## Notes

- The MQTT publish call is commented out in this release, so sensor telemetry is not actively published by the main loop.
- Remote browser control and Audio mode are not included; browser-based Auto/Manual control is introduced in v2.0.0.
- Wi-Fi and broker credentials are stored in firmware source. Configure private credentials before deploying or sharing firmware.

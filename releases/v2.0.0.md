# AI Boat Firmware v2.0.0

**Release date:** 2026-09-28

## Highlights

- Added an HTTP control page hosted by the ESP32 for remote operation from a browser on the same Wi-Fi network.
- Added Auto and Manual operating modes. Switching modes stops the motors; Auto resumes autonomous obstacle avoidance.
- Added manual Forward, Backward, Left, Right, and Stop controls. Drive controls send repeated commands while held and stop on release; a 900 ms firmware timeout stops the motors if browser updates stop arriving.
- Added manual ultrasonic sensor positioning: Left, Right, and Straight move the servo and return a distance with `object`, `clear`, or `no_echo` status.
- Added a status endpoint reporting current mode, movement, and front distance.

## HTTP Interface

- `GET /` serves the control page.
- `GET /api/status` returns the current mode, movement, and front distance.
- `POST /api/mode` selects `auto` or `manual`.
- `POST /api/motor` accepts `forward`, `backward`, `left`, `right`, or `stop`.
- `POST /api/servo` accepts `left`, `right`, or `straight` and returns the measured distance.

Connect the laptop to the same Wi-Fi network as the ESP32 and open the IP address printed in Serial Monitor at 115200 baud. The control page has no login; use it only on a trusted local network.

## Hardware and Firmware

The release retains the ESP32 Arduino firmware, ultrasonic obstacle avoidance, L298N motor control, servo scanning, OLED and LED status, DHT11 readings, Wi-Fi, and password-protected ArduinoOTA support.
